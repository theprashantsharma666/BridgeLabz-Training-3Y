Responsive CSS Cheat Sheet

Filters

Used to change the appearance of images.

filter: grayscale(100%);

Media Queries

Used to apply CSS for different screen sizes.

@media (max-width: 700px)

Responsive Design

Makes a website work properly on different devices.

display: flex;

Typography

Controls the size and appearance of text.

font-size: clamp(1rem, 2vw, 2rem);
