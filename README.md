# BridgeLabz Training 3Y

This repository is a 3rd-year training repository focused on Complete Full Stack Development. It is designed for learning, practice, and building practical web development skills through hands-on projects and exercises.

## Overview

This repository follows a structured approach for organizing frontend practice, assignments, revision work, and reviews during training.

## Repository Name

BridgeLabz-Training-3Y

## Branch Naming Convention

Frontend practice branches should follow these names:
- html-practice
- css-practice
- bootstrap-practice
- revision-problems
- reviews

## Commit Message Format

Use clear and consistent commit messages such as:
- [Name] Add: HTML Forms Assignment
- [Name] Add: CSS Flexbox Practice
- [Name] Add: Bootstrap Grid Exercises
- [Name] Refactor: Responsive Navbar
- [Name] Fix: CSS Media Query Issue
- [Name] Update: Weekly Review

## Purpose of gcr-codebase

The gcr-codebase folder contains programs completed from Guided Coding Resources (GCR), assignments, and practice problems.

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate into the project folder:
   ```bash
   cd BridgeLabz-Training-3Y
   ```
3. Start working inside the relevant practice folder.
